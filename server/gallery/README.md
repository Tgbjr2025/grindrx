# Gallery drop — Lake Michigan bathymetric carve

Photo of the finished "LAKE MICHIGAN — No Sharks, No Salt, No Problem" cherry
plaque, carved with stepped bathymetric depth terraces. Pulled from the phone's
DCIM gallery (shot 2026-08-08, Galaxy S26 Ultra).

- `michigan-carve.jpg` — web-ready, 600×800, EXIF stripped (sized to match the
  other `*-carve.jpg` gallery images)
- `michigan-carve-full.jpg` — full resolution 3000×4000, EXIF stripped

To place it on the CarveForge server's gallery, from a machine with SSH access:

```sh
scp server/gallery/michigan-carve.jpg ubuntu@<ovh-host>:/home/ubuntu/relief-toolpath/static/img/gallery/
```
