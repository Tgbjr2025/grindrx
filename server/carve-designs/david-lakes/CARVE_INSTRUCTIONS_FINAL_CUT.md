# FINAL CUT — legibility pass via CarveForge
### File: `david_lakes_depth_v2.png` · run over the already-carved board

Same board, same image canvas as the original — with the detail carved
deeper: crest line art, ribbon text, EST. 1989, compass + N/E/S/W at 2.3 mm;
pockets around the raised DAVID letters and shield D at 3.0 mm; roads, city
dots and pines at 1.9 mm; ball stitches at 1.6 mm. Verified: nowhere is v2
shallower than the original, so this pass can only remove the difference —
everything already at depth is skimmed or skipped.

## 1. Zero — the whole job
- Board stays clamped. XY zero: the SAME bottom-left corner the original
  job started from (you have it set — don't touch it).
- Z zero: bit tip touched off on the frame rim (untouched original surface).

## 2. CarveForge job setup — the numbers that matter
- Image: `david_lakes_depth_v2.png`
- **Size: EXACTLY what you entered for the original map job.** Open the
  original job on the server and copy its width/height. Same for
  **Max depth** — same number as the original. White = surface, do NOT
  invert. Same values = perfect 1:1 registration; different values = the
  misalignment we just lived through.

## 3. Passes — one bit, no tool change
- **Skip roughing.** Generate/run only the FINISH (or detail) pass with the
  **1/16" tapered** bit: full depth, stepover 25–30 %, feed 700 mm/min,
  plunge 300, 11,000 RPM.
- Max new engagement anywhere is ~2 mm — one pass is fine.
- The bit simply won't fit into features smaller than its tip (small city
  text, grid) — those stay exactly as they are. Intended.
- Expect lots of air-cutting over the open lake floors; the real work is in
  the crest, banner, compass, roads and edges. Roughly 1.5–2.5 h depending
  on your stepover.

## 4. Before pressing start
- Grounded 3-prong charger cable. Watch the feed-override slider for the
  first minutes. Dry-run option: Z-zero 5 mm HIGH for the first minute to
  watch it trace in air, then stop, re-zero properly, restart.

## 5. Finish
Vacuum · light top-face sand · dark wax into every recessed line, wiped off
the surface · oil · hanger. Done — give David his mitten.
