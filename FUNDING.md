# Funding GrindrX

> **Inherited from upstream Open Grind, and the content below is upstream's.** No
> funding route has been set up for GrindrX. This page is kept only so the link
> from upstream's docs is not a dead reference — it is **not** a statement that
> GrindrX accepts donations.

GrindrX is free and open source, and there is no donation mechanism configured
for it. If a funding route is ever added, it belongs here, with the recipient
named — not inherited from a project this fork has no relationship with.

Upstream Open Grind's original text follows. It describes upstream's maintainers
and upstream's contribution list, and **does not apply to GrindrX**:

> Open Grind maintainers and contributors accept donations through their own chosen platforms and payment methods.
>
> You can find the list of persons who made contributions ordered by the value in [GOVERNANCE.md](./GOVERNANCE.md).

Do not donate to anyone named in that text on the strength of this page. See the
banner in [GOVERNANCE.md](./GOVERNANCE.md) for who actually maintains GrindrX.

**DECISION NEEDED** — whether to set up a funding route, and for whom.
